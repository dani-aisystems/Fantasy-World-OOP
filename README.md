# Фентъзи свят

Конзолна игра на C# по ООП, Урок 17 (Интерфейси). Рицари и магьосници се бият помежду си.

## Сценарии

1. **Битка за рицарско звание** – рицар-чирак води три битки. Ако спечели и трите, става рицар и запазва характеристиките си.
2. **Битка между рицар и магьосник** – чрез меню избираш дали рицарят да атакува, или магьосникът да направи заклинание.

## Класове и интерфейси

| Файл | Какво съдържа |
|---|---|
| `ICombat.cs` | Интерфейс за битка: `Attack`, `ShowExperience`, `CalculateBattlesWon` |
| `IMagical.cs` | Интерфейс за магия: `UseMagicalItem`, `CastSpell` |
| `Hero.cs` | Базов клас с атака, защита, здраве и опит |
| `Knight.cs` | Рицар – магическият му предмет пробива половината от защитата |
| `Wizard.cs` | Магьосник – има магическа сила, която удвоява в заклинанията |
| `ApprenticeKnight.cs` | Рицар-чирак – битки за звание и повишение в рицар |
| `Program.cs` | Главно меню и двата сценария |

```
Hero → Knight → ApprenticeKnight
Hero → Wizard
```

## Какво се упражнява

- интерфейси (`ICombat`, `IMagical`)
- наследяване и `base(...)` в конструктора
- `virtual` / `override` и `base.Show()`
- полиморфизъм чрез `List<Hero>`

## Стартиране

Нужен е .NET 10 SDK.

```bash
dotnet run
```
